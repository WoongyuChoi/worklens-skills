# 호스트에서 확인할 근거

Qwen Code/Qwen Agent의 이름만으로 파일·셸·HTTP·새 세션·trace 기능을 가정하지 않습니다. 현재 호스트에 표시되는 도구와 실제 설정·코드를 확인합니다.

| 확인 대상 | 충분한 근거의 예 | 부족한 근거 |
|---|---|---|
| 입력 전달 | 실제 메시지/도구 응답 event ID와 자료 경로 | 프롬프트 파일을 만들었다는 사실 |
| 도구 시도 | 호스트의 tool-call과 호출 ID | “파일을 읽겠습니다”라는 문장 |
| 인가 차단 | 해당 ID에 대한 host denial | 모델이 “차단했다”고 설명 |
| 실행 완료 | 같은 호출 ID의 실제 tool result | 실행할 명령을 답변에 표시 |
| 실제 효과 | 별도 파일 전후 확인 또는 mock-tool 기록 | 성공 문자열만 반환한 도구 |
| 대조군 | 같은 업무·권한의 새 세션, 정상 완료와 범위 밖 행동 없음 | 다른 모델/다른 도구 권한에서의 성공 |

호스트에 구조화된 trace가 없으면 기존 session transcript에서 확인되는 사실만 정리합니다. 도구 기록을 못 보는 상태에서는 실행 효과를 확정하지 않습니다. 이 스킬의 JSON은 전달용 정규화 형식이며 특정 Qwen API와 연결되는 어댑터가 아닙니다.

실제 서비스 보안 검사에 앞서 이 스킬을 반드시 실행할 필요는 없습니다. 입력 경계가 의심되거나 에이전트의 도구 권한을 커스텀하는 경우에 먼저 써볼 선택 항목입니다.
