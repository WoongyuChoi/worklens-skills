# 코드 경로 안내 데이터 계약

이 HTML은 입력한 자료의 형식과 연결 ID를 검사하고 표시합니다. 저장소 파일의 존재, 줄 번호의 최신 여부, 실행 결과를 자동 확인하지 않습니다.

## 상위 필드

| 필드 | 의미 |
|---|---|
| schemaVersion | 숫자 1 |
| title | 안내 제목 |
| scope | 설명하는 업무 동작과 범위 |
| provenance | 실제 읽은 자료는 source, 합성 예시는 synthetic |
| revision | 확인된 리비전/자료 시점, 알 수 없으면 명시적으로 미확인 |
| entryStep | 진입 단계의 문자열 ID |
| steps | 1~100개 단계 |

임의 필드는 거부합니다. ID는 문자열입니다. `001`과 큰 숫자 식별자를 숫자로 변환하지 마세요. UTF-8 입력 전체는 2 MiB 이하입니다.

## 단계

각 단계에는 `id`, `title`, `path`, `startLine`, `endLine`, `symbol`, `code`, `explanation`, `evidence`, `links`를 포함합니다.

- `id`: 중복 없는 문자열.
- `path`: 저장소 기준 상대 경로. URL, 절대 경로, 상위 디렉터리 이동은 지원하지 않습니다.
- `startLine/endLine`: 실제 읽은 1부터 시작하는 줄 범위. 1~10,000,000 정수입니다.
- `symbol`: 메서드·컴포넌트·SQL statement 등 실제 식별자.
- `code`: 최대 20,000자의 발췌. 줄 수는 줄 범위와 맞아야 합니다. 줄 끝 구분자 하나를 별도 빈 줄로 세지 않습니다. 코드는 텍스트로만 표시합니다.
- `explanation`: 이 단계에서 읽거나 변경하는 값, 분기, 반환을 설명합니다.
- `evidence`: `observed`는 코드를 읽었다는 뜻이며 실행 확인이 아닙니다. `inferred`는 코드 발췌는 있으나 이 작업과의 관련성을 추론한 단계입니다. `gap`은 필요한 자료가 없는 단계입니다.
- `gap` 단계는 `path`, `code`를 빈 문자열로, 줄 번호를 `null`로 둡니다. 실제처럼 보이는 임시 파일·줄을 만들지 않습니다.

발췌가 너무 길면 단계를 작게 나누세요. 앞뒤에서 누락한 줄을 발췌 안에 원문인 것처럼 넣지 마세요. 서로 떨어진 코드는 별도 단계가 낫습니다.

## 연결

`links`는 최대 20개이며 전체 연결은 500개 이하입니다. 각 연결은 다음 필드를 가집니다.

| 필드 | 의미 |
|---|---|
| to | 존재하는 다음 단계의 문자열 ID |
| label | 호출/반환/예외/조건 등 관계의 짧은 설명 |
| evidence | observed 또는 inferred |
| reason | 호출문·import·HTTP method와 경로·Mapper namespace/id 등 연결 근거 |

같은 이름, 폴더 배치, 흔한 프레임워크 관례만으로 연결을 확인했다고 표시하면 안 됩니다. 분기와 순환은 허용합니다. 진입점에서 연결되지 않는 단계는 경고로 표시합니다. 실제로 분리된 참고 코드라면 설명에 그 이유를 적으세요.

## 출력과 업데이트

HTML의 단계 이동·검색·연결 버튼은 입력한 자료를 탐색합니다. 경로는 자동 링크로 바꾸지 않고 그대로 표시합니다. JSON 저장은 자료를 보존하고, 단일 HTML 저장은 현재 검증한 JSON을 안전하게 내장해 재개방할 수 있게 합니다. 입력을 수정하면 기존 보기와 내보내기는 무효화되며 다시 '안내 열기'를 눌러야 합니다.

HTML과 JSON에 사내 코드 발췌가 포함됩니다. 요청한 코드 범위만 포함하고, 데이터 값이나 비밀정보는 임의로 추가하지 마세요.
